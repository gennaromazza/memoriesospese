---
name: Navigazione admin globale
description: Scelta di prodotto per la navigazione condivisa del pannello amministratore.
---

Le pagine protette del pannello amministratore devono condividere una sidebar laterale coerente, invece di mostrare un menu principale orizzontale solo nel dashboard.

**Why:** L'utente ha scelto esplicitamente la navigazione laterale in tutto il pannello per orientarsi tra dashboard e pagine admin separate senza cambiare modello di navigazione.

**How to apply:** Quando si aggiungono o spostano pagine admin, mantenere la shell laterale comune e riusare i gruppi, le etichette, gli identificatori e le destinazioni esistenti della navigazione admin. Non rinominare gli stati interni senza una migrazione compatibile.
