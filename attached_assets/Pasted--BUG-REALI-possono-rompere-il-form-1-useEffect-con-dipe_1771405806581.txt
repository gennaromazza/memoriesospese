2️⃣ Calendar onSelect → può passare undefined ❌
onSelect={(date) => {
  field.onChange(date);
  setDatePickerOpen(false);
}}

❌ Problema

Calendar di shadcn può restituire undefined
ma lo schema vuole:

eventDate: z.date().optional()


👉 passi undefined senza controllo
👉 trigger di validazioni strane + sync effetti

✅ Fix
onSelect={(date) => {
  if (!date) return;
  field.onChange(date);
  setDatePickerOpen(false);
}}
