// 📦 Progetto: Memorie Sospese — Upgrade con Abbonamenti e Features a Pagamento
// ⚠️ Obiettivo: Implementare sistema completo di abbonamenti Stripe + accesso funzionalità condizionato in un'app React + Firebase. 
// 🔐 Tutto deve funzionare realmente: NO mock, NO stub, NO "TODO", NO loop di ragionamento.

// ✅ STACK BASE:
- React + TypeScript
- Firebase: Auth, Firestore, Storage, Firebase Hosting
- Stripe per pagamenti
- Firebase Extension "Stripe Subscriptions" già installabile

// ✅ NUOVA ARCHITETTURA RICHIESTA:

1. 🔧 CREAZIONE PIANI DI ABBONAMENTO:
   - Free (0€): 1 galleria, 1000 foto, vocali sblocco futuro, NO watermark, NO CSV, NO commenti, NO download ZIP
   - Starter (10€): 5 gallerie, 5000 foto, vocali sblocco futuro
   - Pro (20€): gallerie illimitate, 25.000 foto, vocali sblocco futuro, CSV, like/commenti, dominio personalizzato, watermark personalizzato
   - Premium (40€): come Pro + download ZIP intera galleria, storage illimitato (fair use 1TB)

2. 🧠 DATI SALVATI SU FIRESTORE:
   - Salva in `users/{uid}/subscription` i seguenti campi aggiornati da Stripe webhook:
     - `plan`: "free" | "starter" | "pro" | "premium"
     - `active`: boolean
     - `expiresAt`: timestamp

3. 🪝 INTEGRAZIONE STRIPE (REALE, NON MOCK):
   - Usa Stripe Checkout
   - Salva `customerId` Stripe in Firestore
   - Al webhook `checkout.session.completed`, salva `plan` nel profilo utente
   - Webhook su Firebase Functions deve aggiornare Firestore
   - Disabilita accesso se subscription `active == false`

4. 🔐 ACCESSO CONDIZIONATO ALLE FEATURE (REALE):
   - Crea hook `usePlanFeatures(userId)` che restituisce oggetto:
     ```ts
     {
       galleryLimit: number | "unlimited",
       maxPhotos: number | "unlimited",
       voiceMemo: true,
       likes: boolean,
       comments: boolean,
       downloadZip: boolean,
       watermarkEnabled: boolean,
       domainCustom: boolean,
       leadsExport: boolean
     }
     ```
   - I componenti devono usare questo hook per abilitare/disabilitare funzionalità
   - In caso di blocco (es. superato limite gallerie), mostra UI con bottone “Fai Upgrade”

5. 📁 LOGICHE TECNICHE ATTIVE:
   - **Creazione Galleria:** blocca se gallerie attive ≥ `galleryLimit`
   - **Upload Foto:** blocca se numero totale ≥ `maxPhotos`
   - **Download ZIP (premium):** implementa con Firebase Function che genera ZIP reale con `archiver` npm e salva in Storage per 5 minuti
   - **Watermark (Pro/Premium):**
     - Consenti caricamento watermark PNG nel profilo fotografo (`storage/watermarks/{uid}.png`)
     - In fase di visualizzazione anteprima (client), sovrapponi con `<img src={watermarkUrl} className="absolute" />` sopra la foto

6. 🌐 DOMINIO PERSONALIZZATO (solo Pro e Premium):
   - Consenti al fotografo di impostare dominio nel proprio profilo (es. `gallery.lucafoto.it`)
   - Salva in Firestore: `studioDomains/{domain}` → { userId, status }
   - Mostra le istruzioni DNS al fotografo (CNAME → hosting.memoriesospese.it)
   - Aggiungi mapping su Firebase Hosting rewrite
   - Carica branding del fotografo in base a `window.location.hostname`

7. 📥 ESPORTAZIONE CSV (solo Pro/Premium):
   - Esporta da `gallery-access/{galleryId}` tutti gli utenti che hanno chiesto la password
   - Scaricabile come file CSV reale (`export-leads.csv`)
   - Generato con `papaparse` o `json2csv`

8. 💳 PAGINA DEI PIANI:
   - Crea `PricingPage.tsx` con tabella a 4 colonne (Free, Starter, Pro, Premium)
   - Ogni piano ha bottone "Prova" che avvia checkout Stripe (o redirect se già abbonato)
   - In alto, mostra il piano attivo (se autenticato)

9. 💥 SICUREZZA:
   - Tutti i check devono essere anche server-side nelle Cloud Functions (non solo UI)
   - Niente accesso alle API ZIP o CSV se il piano non consente

10. 📲 USER EXPERIENCE:
   - In ogni sezione disabilitata (commenti, download ZIP, esportazione), mostra messaggio chiaro:
     “Disponibile nel piano [Pro/Premium]. Fai upgrade ora.” + bottone verso `/pricing`
   - Notifiche toast in caso di limite superato (“Hai raggiunto il massimo di foto consentite nel tuo piano: 5.000/5.000”)

11. 🧪 NO MOCK / NO STUB / NO FAKE:
   - Tutte le chiamate devono essere reali (Stripe live mode o test mode, ma funzionanti)
   - Niente placeholder, niente `TODO`, niente `setTimeout` finti
   - Nessuna funzione deve essere lasciata incompleta

12. 🛠️ TOOLS:
   - Usa `react-stripe-js` per frontend
   - Usa Firebase Admin SDK + `stripe` npm in `functions/` per webhook
   - Usa Firebase `onCall` o REST endpoint dove serve

- Creare account fotografo
- Passare a piano Pro via Stripe
- Accedere a tutte le funzionalità sbloccate realmente
- Visualizzare, scaricare, limitare o negare funzioni in base al piano
