🩵 Soluzione ottimale
✅ 1. Aggiungi un piccolo ritardo (post-render)

Aspetta che tutti i pulsanti data-testid^="button-mobile-assign-" siano visibili prima di mostrare l’onboarding.
In pratica, ritardi di mezzo secondo la comparsa del tooltip.

useEffect(() => {
  const tutorialKey = `gallery-product-assignment-tutorial-${galleryData?.id}`;
  const alreadyShown = localStorage.getItem(tutorialKey);

  if (!alreadyShown && galleryData?.productRequirements?.length > 0) {
    const checkReady = setInterval(() => {
      const target = document.querySelector('[data-testid^="button-mobile-assign-"]');
      if (target) {
        clearInterval(checkReady);
        setTimeout(() => setShowOnboardingSpotlight(true), 300);
      }
    }, 300);
    return () => clearInterval(checkReady);
  }
}, [galleryData]);


➡️ Così il tooltip appare solo quando l’elemento è nel DOM e renderizzato.
Eviti totalmente il posizionamento sbagliato.

✅ 2. Aggiorna la logica del componente OnboardingSpotlight

Assicurati che il componente che usi calcoli la posizione del target ogni volta che cambia visibilità o che la finestra viene ridimensionata:

useEffect(() => {
  if (!isVisible) return;
  const target = document.querySelector(targetSelector);
  if (!target) return;

  const reposition = () => {
    const rect = target.getBoundingClientRect();
    setPosition({
      top: rect.top + window.scrollY - 10,
      left: rect.left + window.scrollX + rect.width / 2,
    });
  };

  reposition();
  window.addEventListener("resize", reposition);
  window.addEventListener("scroll", reposition, true);

  return () => {
    window.removeEventListener("resize", reposition);
    window.removeEventListener("scroll", reposition, true);
  };
}, [isVisible, targetSelector]);


👉 in questo modo, anche se l’utente scrolla o ridimensiona la finestra, il tooltip resta ancorato perfettamente al pulsante.

✅ 3. Centra visivamente il box

Aggiungi una piccola correzione CSS per centrarlo sopra (o sotto) il target:

.onboarding-tooltip {
  transform: translate(-50%, -120%);
  transition: transform 0.2s ease, opacity 0.2s ease;
  max-width: 280px;
  z-index: 9999;
}


Se preferisci che appaia sotto al pulsante (quando è vicino al bordo superiore), puoi farlo dinamicamente:

const rect = target.getBoundingClientRect();
const isTopHalf = rect.top < window.innerHeight / 2;
const yOffset = isTopHalf ? rect.bottom + 12 : rect.top - tooltipHeight - 12;

✅ 4. (Facoltativo) Scroll automatico verso il pulsante target

Per far sì che il tooltip sia sempre visibile anche se il pulsante è più in basso nella pagina:

if (target) {
  target.scrollIntoView({ behavior: "smooth", block: "center" });
}
