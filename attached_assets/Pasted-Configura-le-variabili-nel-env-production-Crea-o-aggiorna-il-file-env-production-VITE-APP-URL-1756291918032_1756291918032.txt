Configura le variabili nel .env.production

Crea (o aggiorna) il file .env.production:

VITE_APP_URL=https://gennaromazzacane.it
VITE_BASE_PATH=/memoriesospese/


In sviluppo (vite locale) puoi lasciare il .env così:

VITE_APP_URL=http://localhost:5173
VITE_BASE_PATH=/

2. Come funziona il tuo codice

Il cuore è questa parte:

function getBasePath(): string {
  return import.meta.env.VITE_BASE_PATH || "/";
}


In prod restituirà: "/memoriesospese/"

In dev restituirà: "/"

Poi usi createAbsoluteUrl(path) per creare URL assoluti.
Qui però c'è un problema: il origin prende solo VITE_APP_URL, che nel tuo caso è https://gennaromazzacane.it, ma non aggiunge il base path.
Quindi, ora, un link creato così ti restituisce:
https://gennaromazzacane.it/gallery/xyz ❌
mentre serve:
https://gennaromazzacane.it/memoriesospese/gallery/xyz ✅

3. Modifica da fare in createAbsoluteUrl

Sostituisci questa parte:

const origin = import.meta.env.PROD 
  ? (import.meta.env.VITE_APP_URL?.replace(/\/+$/, "") || "https://gennaromazzacane.it")
  : window.location.origin;

return `${origin}${fullPath}`;


Con questa:

const origin = import.meta.env.PROD
  ? (import.meta.env.VITE_APP_URL?.replace(/\/+$/, "") || "https://gennaromazzacane.it")
  : window.location.origin;

// Assicurati che il base path sia aggiunto solo una volta
const normalizedBasePath = basePath.startsWith("/") ? basePath : `/${basePath}`;
const cleanBasePath = normalizedBasePath.replace(/\/+$/, ""); // rimuove slash finali

return `${origin}${cleanBasePath}/${cleanPath}`;

4. Imposta anche il homepage in package.json

Nel tuo package.json aggiungi:

"homepage": "/memoriesospese/"


Così quando fai npm run build, tutti gli asset (/assets/...) avranno già il path corretto.

5. Ricompilazione e deploy

Dopo aver fatto queste modifiche:

npm run build


Poi carica il contenuto della dist/ nella cartella /memoriesospese/ sul server.

Risultato finale
Ambiente	createAbsoluteUrl('/gallery/xyz') restituirà
Sviluppo	http://localhost:5173/gallery/xyz
Produzione	https://gennaromazzacane.it/memoriesospese/gallery/xyz
