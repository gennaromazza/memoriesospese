✔️ 3. Ottimizza scroll: throttling a 200ms su loadMorePhotos()

In src/pages/Gallery.tsx, trova l’useEffect(() => { window.addEventListener("scroll"... }.

Sostituiscilo con:

const throttledScroll = useMemo(() => {
  let timeout: any;
  return () => {
    if (!timeout) {
      timeout = setTimeout(() => {
        handleScroll();
        timeout = null;
      }, 200);
    }
  };
}, [handleScroll]);

useEffect(() => {
  window.addEventListener("scroll", throttledScroll);
  return () => window.removeEventListener("scroll", throttledScroll);
}, [throttledScroll]);
