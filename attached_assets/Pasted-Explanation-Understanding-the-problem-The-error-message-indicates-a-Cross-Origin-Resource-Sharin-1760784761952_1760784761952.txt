Your web page, hosted at https://65b2695f-b200-424b-9509-5c251e0658fe-00-8qf1iviax1yg.spock.replit.dev, is trying to make a request to a resource located at a different origin: https://us-central1-wedding-gallery-397b6.cloudfunctions.net.

Browsers implement a security feature called the Same-Origin Policy, which by default restricts requests to resources from different origins. To allow cross-origin requests, the server hosting the requested resource must explicitly permit it by including specific CORS headers in its response.
