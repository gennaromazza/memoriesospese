Ecco i 4 documenti chiave che verrebbero creati e collegati tra loro.
A. Il Cliente (clienti)
Viene creato un record anagrafico unico.
code
JSON
{
  "id": "hash_giusyanzalone1993",
  "nome": "Giusy",
  "cognome": "Anzalone",
  "email": "giusyanzalone1993@gmail.com",
  "telefono": "3404111171",
  "indirizzo": "Via Roma 10, Napoli"
}
B. Il Lavoro (jobs)
Il contenitore principale dell'evento.
code
JSON
{
  "id": "job_12345",

  "eventDate": "2026-04-18T00:00:00.000Z",
  "status": "confermato",
  "clientiIds": ["hash_giusyanzalone1993"],
  "financials": {
    "totalePreventivato": 2750,
    "totalePagato": 300,        // Acconto
    "saldoResiduo": 2450,       // 2750 - 300
    "totaleOrdini": 2750
  },
  "quoteIds": ["quote_987"],
  "orderIds": ["order_456"]
}

D. Lo Scadenzario Pagamenti (paymentSchedules)
Generato automaticamente perché c'è un acconto > 0.
code
JSON
{
  "id": "ps_order_456",
  "jobId": "job_12345",
  "totale": 2750,
  "totalePagato": 300,
  "saldoResiduo": 2450,
  "payments": [
    {
      "id": "pay_1",
      "tipo": "acconto",
      "importo": 300,
      "stato": "pagato",        // <--- Già segnato come pagato
