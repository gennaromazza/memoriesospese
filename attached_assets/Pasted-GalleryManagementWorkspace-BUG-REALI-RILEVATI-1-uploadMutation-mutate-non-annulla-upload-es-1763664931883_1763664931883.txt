✅ BUG REALI RILEVATI
1. ❗ uploadMutation.mutate() non annulla upload esistenti

Se l’utente trascina nuovi file mentre un upload è in corso → parte un secondo upload in parallelo, sovrascrivendo uploadProgress.

Effetto: barra imprevedibile, mutazioni concorrenti che aggiornano la stessa gallery.

Fix: bloccare quando uploadMutation.isPending === true.

if (uploadMutation.isPending) return;

2. ❗ Controllo scadenza selezione non sempre corretto

La logica:

const isDeadlinePassed = gallery?.selectionDeadline && gallery.selectionDeadlineEnforced && deadlineDate
  ? new Date() > deadlineDate
  : false;


Se selectionDeadline === null → isDeadlinePassed = false, ok.

MA se selectionDeadline esiste ma deadlineDate non è convertibile → sempre false, ma avrebbe dovuto segnalare l’errore.

Fix: fallback contro timestamp Firestore corrotti.

3. ❗ allPhotos viene caricata solo se gallery.selectionEnabled
enabled: !!galleryId && !!gallery?.selectionEnabled


❌ Se vuoi vedere le foto anche in tab Settings o Upload → non vengono mai caricate.

Effetto: tab Upload e Settings non hanno accesso a allPhotos.

Fix: separare le query.

4. ❗ selectedPhotos può causare crash se gallery.selectedPhotoIds è undefined
gallery?.selectedPhotoIds?.includes(photo.id)


Qui è ok perché hai ?., ma poi usi:

(selectedPhotos.length > 0)


Se una delle due query è lenta → salto temporaneo tra array vuoti che fa lampeggiare la UI.

Fix: porta a useMemo e placeholder UI.

5. ❗ Rischio race condition su photoCount

Sul server:

newPhotoCount = (gallery?.photoCount || 0) + photos.length


⚠️ Se due utenti caricano file contemporaneamente → photoCount perde incrementi.

Fix tecnico:

usare Cloud Function lato server

utilizzare increment(photos.length) in Firestore

import { increment } from "firebase/firestore";
updateGallery(galleryId, { photoCount: increment(photos.length) });

6. ❗ Pulizia filename (regex) non sempre corretta
filename.match(/^\d+-(.+)$/)


Se un file contiene numeri prima del nome → regex sbaglia.

Miglioramento:

replace(/^\d{10,15}-/, '')


Oppure salvare filename originale in Firestore.

7. ❗ Badge prodotto può generare warning “key duplicate”

prodIdx è una stringa, e può ripetersi in edge cases.

Usa:

key={`${photo.id}-${prodIdx}`}

  return allPhotos.filter(photo => gallery.selectedPhotoIds?.includes(photo.id));
}, [gallery, allPhotos]);
