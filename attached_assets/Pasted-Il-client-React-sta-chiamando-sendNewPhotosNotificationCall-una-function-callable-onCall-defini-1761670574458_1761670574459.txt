Il client React sta chiamando sendNewPhotosNotificationCall, una function "callable" (onCall) definita in Firebase (functions.https.onCall(...)).

Ricevi un errore CORS quando provi a chiamarla da frontend su Replit.

Il messaggio è:

Access to fetch at 'https://us-central1-wedding-gallery-397b6.cloudfunctions.net/sendNewPhotosNotificationCall' from origin 'https://65b2695f-...replit.dev' has been blocked by CORS policy

🔍 Problema reale

Le Firebase Callable Functions (onCall) NON supportano CORS personalizzato.

Queste funzioni sono pensate per essere chiamate via httpsCallable() dalla SDK Firebase, non via fetch() diretto da browser.

Nel tuo caso stai usando fetch() via funzione sendNewPhotosNotificationHTTP() nel client, verso sendNewPhotosNotification che è disabilitata, mentre sendNewPhotosNotificationCall è ancora una callable e quindi:

✅ httpsCallable → OK
❌ fetch() verso onCall → Errore CORS

✅ Soluzione consigliata

Hai già una function alternativa perfettamente progettata per risolvere il problema:

export const sendNewPhotosNotificationPublic = functions
  .runWith({ secrets: ['REPL_IDENTITY'] })
  .https.onRequest(async (req, res) => {
    // ...


Questa function:

È un endpoint HTTP normale.

Supporta CORS dinamico (anche da Replit).

Gestisce correttamente l’autenticazione via Firebase Bearer Token.

Fa tutto quello che ti serve.

✅ Azioni da fare ora
