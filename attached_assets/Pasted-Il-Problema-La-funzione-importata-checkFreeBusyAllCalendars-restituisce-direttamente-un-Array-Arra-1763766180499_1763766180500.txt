Il Problema: La funzione importata checkFreeBusyAllCalendars restituisce direttamente un Array (Array<{start, end, ...}>), ma nel codice delle rotte la stiamo trattando come un oggetto che contiene una proprietà .busyPeriods. Di conseguenza, busyPeriodsResult.busyPeriods è undefined, il fallback || [] scatta sempre, e il sistema pensa che il calendario sia sempre vuoto.

Azione Richiesta: Modifica server/routes/consultation-routes.ts correggendo tutte le occorrenze (sono 4) dove viene chiamata checkFreeBusyAllCalendars. Rimuovi il riferimento inesistente a .busyPeriods.

Ecco i Diff specifici da applicare:

1. Fix in POST /available-slots

TypeScript

// Cerca questo blocco errato:
const busyPeriodsResult = await checkFreeBusyAllCalendars(dayStart, dayEnd);
const googleBusyPeriods = busyPeriodsResult.busyPeriods || [];

// Sostituiscilo con:
const googleBusyPeriods = await checkFreeBusyAllCalendars(dayStart, dayEnd);
// (Rimuovi busyPeriodsResult intermedio se non serve o assegna diretto)
2. Fix in POST /create

TypeScript
