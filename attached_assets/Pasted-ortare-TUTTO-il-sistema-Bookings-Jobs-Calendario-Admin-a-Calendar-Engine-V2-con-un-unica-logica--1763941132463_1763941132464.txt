ortare TUTTO il sistema (Bookings, Jobs, Calendario Admin) a Calendar Engine V2 con un’unica logica centralizzata identica a quella già implementata per le Consultazioni.

1. Crea endpoints:
   - /api/booking/v2/available-slots
   - /api/booking/v2/create

4. Aggiungi bookingToCalendarEvent adapter.

7. Rendi retrocompatibili gli endpoint legacy con 301 redirect.

📌 FASE 2 — JOB SYSTEM INTO V2

5. Usare la stessa logica di Conflict Detection delle consulenze.

   - consultations
   - bookings
   - jobs
   - unifiedEvents (normalizzati Europe/Rome)
3. Il frontend deve leggere SOLELY questo endpoint.
4. Il calendario admin deve mostrare la vera agenda reale (GCAL + sistema).

📌 FASE 4 — CODE CLEANUP
1. Rimuovere TUTTI gli utilizzi di:
   - checkFreeBusy
   - checkFreeBusyAllCalendars
   - getEvents (vecchio)
   - createEuropeRomeDate
   - timezone auto-gestito

📌 FASE 5 — VALIDAZIONE
