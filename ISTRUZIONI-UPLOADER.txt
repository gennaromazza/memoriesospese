COSA SERVE (solo la prima volta):
──────────────────────────────────
1. Node.js installato sul tuo PC
   → Scaricalo da: https://nodejs.org
   → Scegli la versione "LTS" e installala normalmente

2. Copia questi due file nella stessa cartella sul tuo PC:
   - uploader-pc.js
   - package-uploader.json   (rinominalo in: package.json)

3. Apri il terminale (cmd o PowerShell) in quella cartella
   e scrivi:
      npm install
   Attendi che finisca (~30 secondi)

═══ FATTO! Non devi fare altro. ═══════════════════════════


COME USARLO OGNI VOLTA:
─────────────────────────────────────────────────────────────
1. Apri il terminale (cmd o PowerShell)
2. Entra nella cartella dove hai salvato i file:
      cd C:\Users\TuoNome\Desktop\Uploader
3. Esegui:
      node uploader-pc.js

Lo script ti guida passo dopo passo e chiede:

  ① Nuova galleria o aggiungi foto a una esistente?
  ② Nome, data, luogo, descrizione
  ③ Cliente da associare (cerca per nome/email)
  ④ Job da collegare (lista selezionabile)
  ⑤ Tipo di accesso:
        Pubblica  /  Password  /  Tema speciale + PIN
  ⑥ Selezione foto per il cliente:
        Modalità like ✅ o dislike ❌, numero foto, scadenza
  ⑦ Video YouTube da associare
  ⑧ Percorso cartella con le foto


COPERTINE (convenzione automatica):
─────────────────────────────────────────────────────────────
Puoi impostare le copertine semplicemente nominando il file
con il prefisso "_copertina" (es. _copertina.jpg).
Lo script le rileva automaticamente:

  📁 Matrimonio Rossi
    ├── _copertina.jpg          ← copertina della GALLERIA
    ├── 001.jpg
    ├── 002.jpg
    ├── 📁 01-Chiesa
    │   ├── _copertina.jpg      ← copertina del capitolo "01-Chiesa"
    │   ├── chiesa-001.jpg
    │   └── chiesa-002.jpg
    └── 📁 02-Ristorante
        ├── _copertina.jpg      ← copertina del capitolo "02-Ristorante"
        ├── cena-001.jpg
        └── cena-002.jpg

• Le foto _copertina vengono caricate normalmente nell'album
  E impostate come copertina della galleria / del capitolo.
• Se non metti nessun file _copertina, non c'è problema:
  le copertine resteranno vuote (impostabili dopo dal pannello).


ORGANIZZAZIONE DELLE FOTO:
─────────────────────────────────────────────────────────────
• Cartella SENZA sottocartelle → tutte le foto in un unico blocco

• Cartella CON sottocartelle → ogni sottocartella diventa un
  capitolo nella galleria

  Esempio:
    📁 Matrimonio Verdi
      📁 01-Chiesa
      📁 02-Villa
      📁 03-Torta-e-Balli

  Le sottocartelle vengono ordinate alfabeticamente,
  quindi usa numeri davanti al nome per controllare l'ordine.


TEMI SPECIALI DISPONIBILI:
─────────────────────────────────────────────────────────────
  🎄 Natale          🎭 Carnevale       💕 San Valentino
  🐰 Pasqua          🎃 Halloween

Per i temi speciali è obbligatorio un PIN (min. 4 caratteri).
Il PIN deve essere unico: lo script verifica automaticamente.
Password e Tema speciale sono MUTUAMENTE ESCLUSIVI.


SELEZIONE FOTO:
─────────────────────────────────────────────────────────────
Puoi abilitare la modalità selezione per il cliente:
  • Like ✅   → il cliente sceglie le foto che VUOLE
  • Dislike ❌ → il cliente esclude le foto che NON vuole
  • Numero di foto da selezionare (oppure "libera" senza limite)
  • Scadenza entro cui completare la selezione


FORMATI FOTO SUPPORTATI:
─────────────────────────────────────────────────────────────
JPG, JPEG, PNG, GIF, WEBP, BMP, TIFF, HEIC, HEIF, AVIF


DOMANDE FREQUENTI:
─────────────────────────────────────────────────────────────
Q: Come inserisco il percorso della cartella?
A: Trascina la cartella direttamente sul terminale —
   il percorso viene incollato automaticamente.

Q: Posso chiudere il terminale durante l'upload?
A: No, lascia aperto fino al completamento.
   Vedrai il contatore: 📷   45/350  nome-file.jpg

Q: Se un file fallisce, le altre foto si caricano lo stesso?
A: Sì. Alla fine vedi l'elenco degli eventuali errori.

Q: Posso aggiungere video YouTube alla galleria?
A: Sì, lo script te lo chiede. Puoi aggiungere
   quanti URL YouTube vuoi.

Q: Il cliente riceve un'email quando creo la galleria?
A: Solo se configuri l'email nel pannello admin separatamente.
   L'uploader associa il cliente ma non invia email autonomamente.
